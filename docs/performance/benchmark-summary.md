- CPU: AMD64 Family 26 Model 68 Stepping 0, AuthenticAMD
- Logical threads: 16
- GPU: NVIDIA GeForce RTX 5070 Ti/PCIe/SSE2
- OpenGL: 3.3.0 NVIDIA 591.86
- Window/backbuffer: 1280x720
- Build: Release
- VSync: Off (`glfwSwapInterval(0)`)
- Render mode: Solid, fixed camera fitted to model bounds
- Frame warm-up/samples: 120/600
- Load warm-up/samples: 1/3 (warm filesystem cache)
- GPU upload samples: 10 (`glFinish` after upload)
- Picking warm-up/samples: 1/10

## Interpretation boundary

`model_load` includes file read, Assimp import/post-processing, and conversion to DentalViz CPU mesh data. Upload is CPU-observed wall time through `glFinish`; it is not a GPU timer query. CPU frame time measures clear, uniform submission, draw submission, event polling, and VSync-off buffer swap without a per-frame `glFinish`; it must not be presented as GPU execution time. Picking measures the current AABB gate plus brute-force nearest ray/triangle search.

Every individual measured sample is stored in `benchmark-raw.csv`.
